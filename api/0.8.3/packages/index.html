ObsPy Library Reference¶

The functionality is provided through the following packages:

General Packages

obspy.core obspy.core - Core classes of ObsPy
obspy.imaging obspy.imaging - Plotting Routines for ObsPy
obspy.realtime obspy.realtime - Real time support for ObsPy
obspy.signal obspy.signal - Signal Processing Routines for ObsPy
obspy.taup obspy.taup - Travel time calculation tool
obspy.xseed obspy.xseed - Dataless SEED, RESP and XML-SEED read and write support for ObsPy

Waveform Import/Export Plug-ins

obspy.datamark obspy.datamark - DataMark read support for ObsPy
obspy.gse2 obspy.gse2 - GSE2/GSE1 read and write support for ObsPy
obspy.mseed obspy.mseed - Mini-SEED read and write support
obspy.sac obspy.sac - SAC read and write support for ObsPy
obspy.seisan obspy.seisan - SEISAN read support for ObsPy
obspy.seg2 obspy.seg2 - SEG-2 read support for ObsPy
obspy.segy obspy.segy - SEG Y and SU read and write support for ObsPy
obspy.sh obspy.sh - Q and ASC (Seismic Handler) read and write support for ObsPy
obspy.wav obspy.wav - WAV(audio) read and write support for ObsPy

Database or Web Service Access Clients

obspy.arclink obspy.arclink - ArcLink/WebDC request client for ObsPy
obspy.db obspy.db - A seismic waveform indexer and database for ObsPy
obspy.earthworm obspy.earthworm - Earthworm Wave Server client for ObsPy.
obspy.iris obspy.iris - IRIS Web service client for ObsPy
obspy.neries obspy.neries - NERIES Web service client for ObsPy
obspy.seishub obspy.seishub - SeisHub database client for ObsPy
