obspy.core.util.misc.guessDelta¶

guessDelta(channel)[source]¶

Estimate time delta in seconds between each sample from given channel name.

Parameters:channel (str) Channel name, e.g. 'BHZ' or 'H'
Return type:float
Returns:Returns 0 if band code is not given or unknown.

Example

>>> print(guessDelta('BHZ'))
0.1

>>> print(guessDelta('H'))
0.0125

>>> print(guessDelta('XZY'))  
0
