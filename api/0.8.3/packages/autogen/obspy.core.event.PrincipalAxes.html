obspy.core.event.PrincipalAxes¶

class PrincipalAxes(*args, **kwargs)[source]¶

Bases: obspy.core.event.__PrincipalAxes

This class describes the principal axes of a double-couple moment tensor solution. t_axis and p_axis are required, while n_axis is optional.

Parameters:
  • t_axis (Axis) T axis of a double-couple moment tensor solution.
  • p_axis (Axis) P axis of a double-couple moment tensor solution.
  • n_axis (Axis, optional) N axis of a double-couple moment tensor solution.
