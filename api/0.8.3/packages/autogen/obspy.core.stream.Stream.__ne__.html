obspy.core.stream.Stream.__ne__¶

Stream.__ne__(other)[source]¶

Implements rich comparison of Stream objects for ”!=” operator.

Example

>>> from obspy import read
>>> st = read()
>>> st2 = st.copy()
>>> st is st2
False
>>> st != st2
False
