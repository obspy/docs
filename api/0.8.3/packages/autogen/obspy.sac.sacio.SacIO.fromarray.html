obspy.sac.sacio.SacIO.fromarray¶

SacIO.fromarray(trace, begin=0.0, delta=1.0, distkm=0, starttime=UTCDateTime(1970, 1, 1, 0, 0))[source]¶

Create a SAC file from an numpy.ndarray instance

>>> t = SacIO()
>>> b = np.arange(10)
>>> t.fromarray(b)
>>> t.GetHvalue('npts')
10
