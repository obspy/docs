obspy.core.event.Comment._pretty_str¶

Comment._pretty_str(priorized_keys=[], min_label_length=16)¶

Return better readable string representation of AttribDict object.

Parameters:
  • priorized_keys (List of str, optional) Keywords of current AttribtDict which will be shown before all other keywords. Those keywords must exists otherwise an exception will be raised. Defaults to empty list.
  • min_label_length (int, optional) Minimum label length for keywords. Defaults to 16.
Returns:

String representation of current AttribDict object.
