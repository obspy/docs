obspy.seisan.core.isSEISAN¶

isSEISAN(filename)[source]¶

Checks whether a file is SEISAN or not.

Parameters:filename (str) Name of the audio SEISAN file to be checked.
Return type:bool
Returns:True if a SEISAN file.

Example

>>> isWAV("/path/to/1996-06-03-1917-52S.TEST__002")  
True
