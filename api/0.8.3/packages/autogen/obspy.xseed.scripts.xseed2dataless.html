obspy.xseed.scripts.xseed2dataless¶

Note

This script automatically installs during the setup procedure with the name $ obspy-xseed2dataless. For more info on the command line options, please run $ obspy-xseed2dataless --help. Alternatively you can also execute $ python -m obspy.xseed.scripts.xseed2dataless.

A command-line program that converts XML-SEED into Dataless SEED files.
