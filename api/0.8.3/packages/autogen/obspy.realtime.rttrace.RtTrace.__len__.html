obspy.realtime.rttrace.RtTrace.__len__¶

RtTrace.__len__()¶

Returns number of data samples of the current trace.

Return type:int
Returns:Number of data samples.

Example

>>> trace = Trace(data=np.array([1, 2, 3, 4]))
>>> trace.count()
4
>>> len(trace)
4
