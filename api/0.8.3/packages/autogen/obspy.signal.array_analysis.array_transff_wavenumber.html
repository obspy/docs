obspy.signal.array_analysis.array_transff_wavenumber¶

array_transff_wavenumber(coords, klim, kstep, coordsys='lonlat')[source]¶

Returns array transfer function as a function of wavenumber difference

Parameters:
  • coords (numpy.ndarray) coordinates of stations in longitude and latitude in degrees elevation in km, or x, y, z in km
  • coordsys (string) valid values: ‘lonlat’ and ‘xy’, choose which coordinates to use
  • klim either a float to use symmetric limits for wavenumber differences or the tupel (kxmin, kxmax, kymin, kymax)
