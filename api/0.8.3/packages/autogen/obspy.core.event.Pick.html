obspy.core.event.Pick¶

class Pick(*args, **kwargs)[source]¶

Bases: obspy.core.event.__Pick

This class contains various attributes commonly used to describe a single pick, e.g. time, waveform id, onset, phase hint, polarity, etc

Parameters:
  • resource_id (ResourceIdentifier) Resource identifier of Pick.
  • time (UTCDateTime) Pick time.
  • time_errors (AttribDict) AttribDict containing error quantities.
  • waveform_id (WaveformStreamID) Identifies the waveform stream.
  • filter_id (ResourceIdentifier, optional) Identifies the filter setup used.
  • method_id (ResourceIdentifier, optional) Identifies the method used to get the pick.
  • horizontal_slowness (float, optional) Describes the horizontal slowness of the Pick.
  • horizontal_slowness_errors (AttribDict) AttribDict containing error quantities.
  • backazimuth (float, optional) Describes the backazimuth of the Pick.
  • backazimuth_errors (AttribDict) AttribDict containing error quantities.
  • slowness_method_id (ResourceIdentifier, optional) Identifies the method used to derive the slowness.
  • onset (str, optional) Describes the pick onset type. Allowed values are: * "emergent" * "impulsive" * "questionable"
  • phase_hint (str, optional) Free-form text field describing the phase. In QuakeML this is a separate type but it just contains a single field containing the phase as a string.
  • polarity (str, optional) Describes the pick onset type. Allowed values are: * "positive" * "negative" * "undecidable"
  • evaluation_mode (str, optional)

    Evaluation mode of Pick. Allowed values are the following:

    • "manual"
    • "automatic"
  • evaluation_status (str, optional)

    Evaluation status of Pick. Allowed values are the following:

    • "preliminary"
    • "confirmed"
    • "reviewed"
    • "final"
    • "rejected"
    • "reported"
  • comments (list of Comment, optional) Additional comments.
  • creation_info (CreationInfo, optional) Creation information used to describe author, version, and creation time.
