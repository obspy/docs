obspy.signal.tf_misfit.cwt¶

cwt(st, dt, w0, fmin, fmax, nf=100.0, wl='morlet')[source]¶

Continuous Wavelet Transformation in the Frequency Domain.

See also

[Kristekova2006], eq. (4)

Parameters:
  • st time dependent signal.
  • dt time step between two samples in st
  • w0 parameter for the wavelet, tradeoff between time and frequency resolution
  • f frequency discretization, type numpy.ndarray.
  • wl wavelet to use, for now only ‘morlet’ is implemented
Returns:

time frequency representation of st, type numpy.ndarray of complex values.
