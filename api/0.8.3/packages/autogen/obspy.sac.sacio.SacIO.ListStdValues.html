obspy.sac.sacio.SacIO.ListStdValues¶

SacIO.ListStdValues()[source]¶

Convenience function for printing common header values.

Param :None
Returns:None 
>>> from obspy.sac import SacIO  
>>> t = SacIO('test.sac')  
>>> t.ListStdValues()  

Reference Time = 07/18/1978 (199) 8:0:0.0
Npts  =  100
Delta =  1
Begin =  10
End   =  109
Min   =  -1
Mean  =  8.7539462e-08
Max   =  1
Header Version =  6
Station =  STA
Channel =  Q
Event       =  FUNCGEN: SINE

If no header values are defined (i.e. all are equal 12345) than this function won’t do anything.
