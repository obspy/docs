obspy.arclink.client.Client.getStations¶

Client.getStations(starttime, endtime, network)[source]¶

Returns a dictionary of available stations in the given network(s).

Note

Currently the time span seems to be ignored by the ArcLink servers, therefore all possible stations are returned.

Parameters:
  • starttime (UTCDateTime) Start date and time.
  • endtime (UTCDateTime) End date and time.
  • network (str) Network code, e.g. 'BW'.
Returns:

Dictionary of station data.
