obspy.core.event.OriginUncertainty¶

class OriginUncertainty(*args, **kwargs)[source]¶

Bases: obspy.core.event.__OriginUncertainty

This class describes the location uncertainties of an origin.

The uncertainty can be described either as a simple circular horizontal uncertainty, an uncertainty ellipse according to IMS1.0, or a confidence ellipsoid. The preferred variant can be given in the attribute preferred_description.

Parameters:
  • horizontal_uncertainty (float, optional) Circular confidence region, given by single value of horizontal uncertainty. Unit: m
  • min_horizontal_uncertainty (float, optional) Semi-major axis of confidence ellipse. Unit: m
  • max_horizontal_uncertainty (float, optional) Semi-minor axis of confidence ellipse. Unit: m
  • azimuth_max_horizontal_uncertainty (float, optional) Azimuth of major axis of confidence ellipse. Unit: deg
  • confidence_ellipsoid (ConfidenceEllipsoid, optional) Confidence ellipsoid
  • preferred_description (str, optional)

    Preferred uncertainty description. Allowed values are the following:

    • horizontal uncertainty
    • uncertainty ellipse
    • confidence ellipsoid
    • probability density function
