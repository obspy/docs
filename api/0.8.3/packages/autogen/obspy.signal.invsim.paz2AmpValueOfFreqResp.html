obspy.signal.invsim.paz2AmpValueOfFreqResp¶

paz2AmpValueOfFreqResp(paz, freq)[source]¶

Returns Amplitude at one frequency for the given poles and zeros

Parameters:
  • paz Given poles and zeros
  • freq Given frequency

The amplitude of the freq is estimated according to “Of Poles and Zeros”, Frank Scherbaum, p 43.

Example

>>> paz = {'poles': [-4.44 + 4.44j, -4.44 - 4.44j],
...        'zeros': [0 + 0j, 0 + 0j],
...        'gain': 0.4}
>>> amp = paz2AmpValueOfFreqResp(paz, 1)
>>> print(round(amp, 7))
0.2830262
