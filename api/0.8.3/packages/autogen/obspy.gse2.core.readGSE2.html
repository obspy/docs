obspy.gse2.core.readGSE2¶

readGSE2(filename, headonly=False, verify_chksum=True, **kwargs)[source]¶

Reads a GSE2 file and returns a Stream object.

GSE2 files containing multiple WID2 entries/traces are supported.

Warning

This function should NOT be called directly, it registers via the ObsPy read() function, call this instead.

Parameters:
  • filename (string) GSE2 file to be read.
  • headonly (boolean, optional) If True read only head of GSE2 file.
  • verify_chksum (boolean, optional) If True verify Checksum and raise Exception if it is not correct.
Return type:

Stream
Returns:

Stream object containing header and data.

Example

>>> from obspy import read
>>> st = read("/path/to/loc_RJOB20050831023349.z")
