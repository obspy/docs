obspy.core.event.StationMagnitude¶

class StationMagnitude(*args, **kwargs)[source]¶

Bases: obspy.core.event.__StationMagnitude

This class describes the magnitude derived from a single waveform stream.

Parameters:
  • resource_id (ResourceIdentifier, optional) Resource identifier of StationMagnitude.
  • origin_id (ResourceIdentifier, optional) Reference to an origin’s resource_id if the StationMagnitude has an associated Origin.
  • mag (float) Estimated magnitude.
  • mag_errors (AttribDict) AttribDict containing error quantities.
  • station_magnitude_type (str, optional)

    Describes the type of magnitude. This is a free-text field because it is impossible to cover all existing magnitude type designations with an enumeration. Possible values are:

    • unspecified magnitude ('M'),
    • local magnitude ('ML'),
    • body wave magnitude ('Mb'),
    • surface wave magnitude ('MS'),
    • moment magnitude ('Mw'),
    • duration magnitude ('Md')
    • coda magnitude ('Mc')
    • 'MH', 'Mwp', 'M50', 'M100', etc.
  • amplitude_id (ResourceIdentifier, optional) Identifies the data source of the StationMagnitude. For magnitudes derived from amplitudes in waveforms (e. g., local magnitude ML), amplitude_id points to resource_id in class obspy.core.event.Amplitude.
  • method_id (ResourceIdentifier, optional) Identifies the method of magnitude estimation. Users should avoid to give contradictory information in method_id and type.
  • waveform_id (WaveformStreamID, optional) Identifies the waveform stream.
  • comments (list of Comment, optional) Additional comments.
  • creation_info (CreationInfo, optional) Creation information used to describe author, version, and creation time.
