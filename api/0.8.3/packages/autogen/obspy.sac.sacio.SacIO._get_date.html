obspy.sac.sacio.SacIO._get_date¶

SacIO._get_date()[source]¶

If date header values are set calculate date in julian seconds

>>> t = SacIO()
>>> t.fromarray(np.random.randn(100), delta=1.0,                         starttime=UTCDateTime(1970,01,01))
>>> t._get_date()
>>> t.reftime.timestamp
0.0
>>> t.endtime.timestamp - t.reftime.timestamp
100.0
