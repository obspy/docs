obspy.gse2.core.readGSE1¶

readGSE1(filename, headonly=False, verify_chksum=True, **kwargs)[source]¶

Reads a GSE1 file and returns a Stream object.

GSE1 files containing multiple WID1 entries/traces are supported.

Warning

This function should NOT be called directly, it registers via the ObsPy read() function, call this instead.

Parameters:
  • headonly (boolean, optional) If True read only header of GSE1 file.
  • verify_chksum (boolean, optional) If True verify Checksum and raise Exception if it is not correct.
Return type:

Stream
Returns:

Stream object containing header and data.

Example

>>> from obspy import read
>>> st = read("/path/to/y2000.gse")
