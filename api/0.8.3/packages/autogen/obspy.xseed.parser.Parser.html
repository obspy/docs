obspy.xseed.parser.Parser¶

class Parser(data=None, debug=False, strict=False, compact=False)[source]¶

Bases: object

The XML-SEED parser class parses dataless or full SEED volumes.

See also

The SEED file format description can be found at http://www.iris.edu/manuals/SEEDManual_V2.4.pdf.

The XML-SEED format was proposed in:

  • http://www.orfeus-eu.org/Organization/Newsletter/vol6no2/xml.shtml
  • http://www.jamstec.go.jp/pacific21/xmlninja/.
