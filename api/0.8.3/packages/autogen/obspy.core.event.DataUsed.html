obspy.core.event.DataUsed¶

class DataUsed(*args, **kwargs)[source]¶

Bases: obspy.core.event.__DataUsed

This class describes the type of data that has been used for a moment-tensor inversion.

Parameters:
  • wave_type (str)

    Type of waveform data. This can be one of the following values:

    • "P waves",
    • "body waves",
    • "surface waves",
    • "mantle waves",
    • "combined",
    • "unknown"
  • station_count (int, optional) Number of stations that have contributed data of the type given in wave_type.
  • component_count (int, optional) Number of data components of the type given in wave_type.
  • shortest_period (float, optional) Shortest period present in data. Unit: s
  • longest_period (float, optional) Longest period present in data. Unit: s
