obspy.core.event.Tensor¶

class Tensor(*args, **kwargs)[source]¶

Bases: obspy.core.event.__Tensor

The Tensor class represents the six moment-tensor elements m_rr, m_tt, m_pp, m_rt, m_rp, m_tp, where r is up, t is south, and p is east. See Aki & Richards (1980) for conversions to other coordinate systems.
