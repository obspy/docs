obspy.core.preview.mergePreviews¶

mergePreviews(stream)[source]¶

Merges all preview traces in one Stream object. Does not change the original stream because the data needs to be copied anyway.

Parameters:stream (Stream) Stream object to be merged
Return type:Stream
Returns:Merged Stream object.
