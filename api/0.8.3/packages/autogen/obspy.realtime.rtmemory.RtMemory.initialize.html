obspy.realtime.rtmemory.RtMemory.initialize¶

RtMemory.initialize(data_type, length_input, length_output, input_inital_value=0, output_inital_value=0)[source]¶

Create and initialize input and output arrays for this RtMemory object.

Parameters:
  • trace Desired array data-type.
  • length_input (int) length of the input memory array.
  • length_output (int) length of the output memory array.
  • input_inital_value (float, optional) Initialization value for the input memory array (default is 1.0).
  • output_inital_value (float, optional) Initialization value for the output memory array (default is 1.0).
