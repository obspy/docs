obspy.core.utcdatetime.UTCDateTime._setMonth¶

UTCDateTime._setMonth(value)[source]¶

Sets month of current UTCDateTime object.

Parameters:value (int) Month

Example

>>> dt = UTCDateTime(2012, 2, 11, 10, 11, 12)
>>> dt.month = 10
>>> dt
UTCDateTime(2012, 10, 11, 10, 11, 12)
