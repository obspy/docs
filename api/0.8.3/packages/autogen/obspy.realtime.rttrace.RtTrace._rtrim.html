obspy.realtime.rttrace.RtTrace._rtrim¶

RtTrace._rtrim(endtime, pad=False, nearest_sample=True, fill_value=None)¶

Cuts current trace to given end time. For more info see trim().

Example

>>> tr = Trace(data=np.arange(0, 10))
>>> tr.stats.delta = 1.0
>>> tr._rtrim(tr.stats.starttime + 2)
>>> tr.data
array([0, 1, 2])
>>> tr.stats.endtime
UTCDateTime(1970, 1, 1, 0, 0, 2)
