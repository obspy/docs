obspy.sac.core.isSAC¶

isSAC(filename)[source]¶

Checks whether a file is a SAC file or not.

Parameters:filename (string) SAC file to be checked.
Return type:bool
Returns:True if a SAC file.

Example

>>> isSAC('/path/to/test.sac')
